🎛️ MAIN CONTROLS - With Visual Examples

Top Bar - Music Theory Engine

  • Root Note: The home note of your song
    Example: C = C Major scale (C,D,E,F,G,A,B), A = A Minor (A,B,C,D,E,F,G)
  • Scale Mode: Mood of the song
    Example: Major = happy (C-E-G), Natural Minor = sad (A-C-E), Dorian = cool jazzy (D-F-A), Blues = soulful
  • Harmonic Extension: Chord complexity
    Example: Triads = 3 notes (basic), 7ths = 4 notes (jazzy), 13ths = 6 notes (rich), Polychords = 2 chords stacked
  • Genre Preset: Sets rhythm & instruments
    Example: Trance = 16th arp + supersaw, Lo-Fi = slow + Rhodes + vinyl drums, Techno = 4x4 kick + acid bass
  • Bars: Length
    Example: 4 Bars = 8 seconds at 128 BPM, 16 Bars = 32 seconds

🔢 BPM & Repeat

  • BPM: Speed - Example: 80 BPM = slow ballad, 128 BPM = dance, 170 BPM = drum & bass. Formula: 1 bar = (60/BPM)*4 seconds
  • Repeat Times: How many loops before stopping - Example: 0 = infinite (use with Loop ON), 3 = plays 3 times then stops even if Loop ON

🎹 PIANO ROLL - How To Read It

Each track has a piano roll - this is where you SEE the music. We made an interactive diagram:

Vertical = Pitch

  • Top = high notes (e.g., C6)
  • Bottom = low notes (e.g., C2)
  • White keys = white piano keys, Grey = black keys
  • Example: Bass track shows notes at bottom (C2), Bells at top (C6)

Horizontal = Time

  • Left = start of song, Right = end
  • Grid lines: thick = bar, thin = beat
  • Colored blocks = notes, length = duration
  • Green line = playhead (where you are now)
  • Example: A 4-beat note spans 4 grid squares

🎼 12 TRACKS - How They Work Together

Your song has 12 layers, like a real band. Each has a role:

Chord Stacks (Harmony)
Plays chords: C → Am → F → G
Example: C Major = C+E+G notes together, 14 steps long
Bassline (Low End)
Root note every 4 steps, monophonic
Example: C2, C2, F2, G2 - cuts previous note instantly
Arpeggiator (Rhythm)
Plays chord notes one by one fast
Example: C+E+G+E pattern every 2 steps
Lead Melody (Top Line)
Random scale notes, catchy
Example: E5, G5, A5, C6 every 4 steps

Per-Track Controls - With Examples

  • Instrument Dropdown: 15-22 choices per track, all audible with own sound font
    Example: Bass: Sub Bass (sine 350Hz) vs Moog Bass (saw 850Hz) vs 808 (sine + pitch drop) - each sounds totally different
  • 🎲 Dice (per track): Randomizes only this track + its instrument
    Example: Don't like bass? Click 🎲 on Basslane → new bassline + new bass instrument instantly
  • 🧹 Clear: Removes all notes from this track only
    Example: Clear Bells → no bells, keep everything else. Good for minimal track
  • 🔒 Lock: Locks track so Randomize All won't change it
    Example: Lock Bass + Drums → Randomize All changes only melody but keeps groove
  • M Mute / S Solo: Mute = red, Solo = green
    Example: Solo Lead → hear only lead, Mute Pad → remove pad texture
  • 💾 Export: Export single track as MIDI or WAV
    Example: Export Bass as MIDI → drag into FL Studio/Ableton
